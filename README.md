# Smart Leads Dashboard

Original MERN + TypeScript internship assignment starter.

## Stack
- React + TypeScript + Tailwind
- Node + Express + TypeScript
- MongoDB + Mongoose
- JWT Auth
- RBAC
- Lead CRUD
- Filtering + Pagination

## Run

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
